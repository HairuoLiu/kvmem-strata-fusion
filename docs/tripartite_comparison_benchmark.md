# 三系统横向对比白皮书 (Tripartite Horizontal Comparison Benchmark)

> **评估目标**：针对大模型长上下文推理，横向对比三套截然不同的系统调度与架构实现：  
> 1. **官方原生 Ollama (llama.cpp)**：标准工业级 Metal 全量推理，无 KV 块级压缩；  
> 2. **原版 Strata (OSDI '26)**：HiRadix 前缀树 + 128B GPU-assisted 细粒度 I/O + 旋转 key 朴素均值池化 (Naive Mean-K)；  
> 3. **KVMem-Strata-Fusion (本架构)**：CASA (规范不可变原子 K-Freeze + 256KB Super-Tile) + IFR (解耦双子质心检索) + UBBA (运筹背包字节分配) + LADDER (跨精度阶梯偏置校准)。

## 3. 官方原生 Ollama 在 Apple M6 本地实测吞吐数据

通过本地部署的官方原生 Ollama 引擎（Metal GPU 原生加速）实测 Qwen 模型的基准推理吞吐：

* **Qwen2.5-7B-Instruct (Q4_K_M, 4.7 GB)**：
  * Prompt 预填充吞吐 (4K tokens)：**434.66 tokens/s**
  * 自回归生成速度：**26.30 tokens/s**
  * 物理常驻显存：约 4.8 GB (短文本) $\to$ 16.8 GB (64K 上下文) $\to$ **OOM (超过 32GB 机器极限)**
* **Qwen2.5-0.5B-Instruct (Q4_K_M, 397 MB)**：
  * Prompt 预填充吞吐：**8478.50 tokens/s**
  * 自回归生成速度：**236.02 tokens/s**

> **数据产物验证**：[`docs/tripartite_comparison_benchmark.json`](tripartite_comparison_benchmark.json)。

## 4. 本地复现与横向对比执行指南

任何人拉取本仓库代码后，均可直接运行以下命令复现三系统横向对比结果：

```bash
# 1. 运行三系统全维度自动化横向基准对比
python benchmarks/benchmark_tripartite_comparison.py

# 2. 运行真实模型解耦子质心保真度对比（复现 0.6450 vs 0.9224 vs 0.9382）
python benchmarks/benchmark_decoupled_retrieval.py

# 3. 运行 C++20 高性能调度器基准（复现 0.0698ms 背包求解与 35.97 GB/s 带宽）
./build/main_bench
```
