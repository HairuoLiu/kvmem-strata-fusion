## 3. 四大关键子能力深度解构与优化原理

### 3.1 检索保真度优化：从 Mean-K 稀释到双子质心分裂 (IFR)
* **原版痛点**：在 32-token 块中，如果存在 1 个高重要性针尖 token 与 31 个无关背景 token，均值池化后的向量打分仅为 $1/32 \approx 0.031$。在 10M 规模（312,500 个候选块）且选择率为 0.033% 时，背景噪声使得针尖块必被沉底丢弃（召回率跌至 0%）。
* **本系统优化**：
  1. 引入块内离散度度量 $dev\_meta = \max_i \|k_i - \bar{k}\|_2$；
  2. 动态检测到离散异常时，虚拟分裂为双子质心 $[k_{\text{needle}}, \bar{k}_{\text{residual}}]$；
  3. 针尖打分恢复全量峰值，在低信噪比与大规模扩展下均保持 **100.0%** 召回。
  4. *注意*：阈值必须采用自适应动态门限（$\mu_{\text{block}} + 3\sigma_{\text{block}}$），防止背景高方差时虚警率饱和（$\sigma \ge 0.10$ 时静态 0.85 虚警率达 99.85%）。

### 3.2 混精度注意力校正：从注意力盗窃到 Tier-Bias 无偏补偿 (LADDER)
* **原版痛点**：量化噪声 $\varepsilon_t \sim \mathcal{N}(0, \sigma_t^2)$ 在 Softmax 指数运算下放大：
  $$\mathbb{E}[\exp(\ell + \varepsilon_t)] = \exp(\ell) \cdot \exp\left(\frac{\sigma_t^2}{2}\right)$$
  INT2 块（$\sigma \approx 0.634$）的未校准权重会系统性虚高膨胀 **22.3%**，导致模型将注意力错误投向劣质压缩块，产生极高 PPL 漂移。
* **本系统优化**：
  1. 在 Softmax 分数前注入解析常数偏置 $b_t = -\frac{\sigma_t^2}{2} = -\frac{(\rho_t \cdot s)^2}{2}$；
  2. 抵消对数正态膨胀乘数，混精度下的期望注意力权重偏差压降至 **0.0012**。

### 3.3 物理存储架构解耦：从 Delta re-RoPE 到 Paged K-Freeze (CASA)
* **原版痛点**：原生 KVMem 每次换入块时需要按目标物理位置做重旋转（Delta re-RoPE）。经过多次搬运量化后，误差在线累积，在搬运约 250 次后触发数值崩溃，被迫从磁盘全量重读原始数据（5× I/O 放大）。
* **本系统优化**：
  1. 遵奉 **K-Freeze 原则**：Key 向量在 Prefill 阶段按原始全局位置 $n$ 旋转一次入库，终身冻结；
  2. 利用 **PagedAttention 虚拟页表** 进行逻辑寻址，计算时直接执行原生 Tensor Core 2D GEMM；
  3. 相对旋转不变性误差控制在机器极限（$\Delta < 10^{-12}$），彻底消除了重建悬崖。

### 3.4 调度与运筹求解加速：从 Python 启发式到 C++20 纳秒级控制面 (UBBA)
* **原版痛点**：原生 Python 求解器在大并发下存在 GIL 锁竞争，调度 10,000 个块耗时高达 10~16 ms，吞食了大模型解码的时间预算。
* **本系统优化**：
  1. 采用 C++20 与 16 字节缓存对齐 POD 结构体重写求解器；
  2. 引入 4-Pass 256 桶无锁基数排序（LSD Radix Sort）；
  3. 10,000 个块求解耗时缩短至 **69.75 µs（0.07 ms）**，吞吐量达到 **1.43 亿块/秒**，满足大模型高并发实时调度 SLA。

## 4. 架构治理与降级路径 (Subsystem Degradation)

确立**子系统级降级**原则，各模块失效兜底链路如下：
- **CASA 失败** $\to$ 回退至标准 PagedAttention 局部滑窗（不执行持久化大块聚簇）。
- **IFR 双子质心饱和** $\to$ 动态切回单质心 Mean-K 并扩大 $n_{\text{probe}}$ 探查扇出。
- **UBBA 超时** $\to$ 降级至 2 级静态水位截断。
- **LADDER 深度压缩失真** $\to$ 截断至 FP8/INT4 4.35× 阶梯，停止 1-bit Quad-Merge。
