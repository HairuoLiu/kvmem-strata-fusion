## 2. 与我们之后做的研究（v2 审计）有什么区别

我们的 v2 研究（`da20e80` 及之后）在同一时间段产出了：位置匹配版 recall **B/A=1.40×**（撤回 v1）、**重定位惩罚**（Qwen2.5 L12 0.877→0.563、re-RoPE 打块中心 11/12 胜）、**centroid law**（保真只由 tokens/centroid 决定，组内 spread ≤0.06）、**逐层位置先验**（α 0.1→0.9，浅层 ρ=−0.091）、**因果三分**（RoPE +0.254 / 质心 +0.044 / 迁移 −0.31）、S1–S3 自检。

对照：

1. **干预层级完全不同**
   - 他们的回复 = **「门限标定」微层**：一个数（0.868）+ 一个默认开关。
   - 我们的研究 = **「索引正确性 + 注意力保真」宏层**：Mean-K 保真、RoPE 处理、质心分辨率、重定位、逐层先验。
   - 两者不在同一层面，本质是「修一个开关」vs「重建正确性理论」。

2. **他们验证了我们的一条纪律（共识）**
   - 采纳 0.868（去 RoPE 归一化空间的 norm_max p95），印证了我们 v2 反复强调的**「召回/离散度必须声明所在相关性空间」**。这点上对上了。

3. **他们没采纳我们更深层的结构结论（分歧 / 缺口）**
   - **逐层阈值（D）**：我们的逐层位置先验 + 他们自己测出的 20× 层差，都要求阈值**逐层**。他们用单一全局 0.868 → 浅层会过触发、深层会漏触发。
   - **anti-collapse 是不是该打的主战场**：我们的因果三分显示 **RoPE 处理（+0.254）是最大单一杠杆，比质心分辨率（+0.044）大 5.8 倍**，dispersch.gating 远不是大头。他们精修门限，但**没有质疑「dispersion 门限是不是正确战场」**——仍默认 anti-collapse 是核心机制。
   - **centroid law**：我们证明「同等预算下多加质心优于缩小块」（B32/m4 0.711 > B8/m1 0.654）。他们的 doublet 分裂（m=2）**方向吻合**「多加质心」，但没引用 / 泛化到我们的质心定律，仍停留在「块内是否要拆成双峰」的启发式。
   - **重定位惩罚 & re-RoPE**：**完全在他们的回复范围外**。他们的 IFR 作用于**原位块**；KVMem 的 compaction / 重定位 / re-RoPE 是我们的层。我们的重定位惩罚（compaction 不是免费的）对他们当前的 in-place 索引不构成约束，但一旦要接 KVMem 就必须面对。

4. **方法学缺口（E）仍在**
   - 他们仍在比真实小 ~2× 的合成数据上测 anti-collapse；我们 v2 全程用**真实 Qwen 去 RoPE 键**。基准不统一，跨组结论难直接比较。

## 3. 一个残留风险（建议回他们的第二批 comment）

**needle 检测改用原始 Euclidean 永远**：我们在 review 里警告过 **massive-activation 伪影**——σ≈8.03 是 L2 幅度、不是语义。用原始 L2 选离群 token，可能挑到 **massive-channel token** 而非语义离群点。门限判定现已用归一化（对了），但 needle 选点仍被幅度误导。
**建议**：needle 检测也走归一化方向距离（或与幅度并列报告），避免把「数值大」误当「语义离群」。
