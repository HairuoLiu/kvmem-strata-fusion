# KVMem AI 客户端使用手册 (User Manual & Quickstart)

欢迎使用 **KVMem AI 客户端**！本软件是一款为本地大模型推理打造的现代桌面端/Web 交互客户端。

它拥有比肩 **Ollama** 与 **Strata** 的极简现代 UI 界面，支持多轮对话、流式打字机输出、实时速度监控与系统资源监控；而在底层算法上，内置了我们自研的 **KVMem 超长上下文加速引擎（CASA 规范存储 + IFR 解耦质心检索 + LADDER 阶梯量化）**，彻底打破传统本地推理显存暴涨与上下文遗忘的瓶颈。

## 1. 一键启动客户端界面

### 环境要求
* **操作系统**：macOS (Apple Silicon M 系列) 或 Linux x86_64
* **Python 环境**：Python 3.9 及以上

### 极速启动
在项目根目录下运行服务：

```bash
# 1. 激活虚拟环境并启动客户端服务端
.venv/bin/python web/server.py
```

* 终端将显示：  
  `🚀 KVMem AI Studio is running at: http://127.0.0.1:8080`
* **打开电脑浏览器访问**：👉 **`http://127.0.0.1:8080`**

### 💬 对话视图 (Chat)
* **模型热切换**：在对话区顶部下拉菜单自由选择本地已下载的模型（如 `qwen2.5:7b`、`qwen2.5:0.5b`）。
* **流式打字机效果**：模型逐词实时吐字，响应迅速。
* **实时性能小标（Metrics Tag）**：每条回复下方均精准显示当前回复的**生成速度（tokens/s）**、**总 Token 数**、**耗时**以及加速状态。
* **快捷按键支持**：
  * `Enter`：发送消息；
  * `Shift + Enter`：换行输入。

### 📊 系统监控视图 (Monitor)
点击顶部导航的 **Monitor** 标签，实时洞察模型运行状态与自研引擎收益：
* **KV Cache 物理压缩比**：直观看到当前 **8.0×** 压缩比（显存/磁盘占用压降 87.3%）。
* **检索保真度 (Recall@64)**：实时展示解耦子质心带来的 **0.9382** 高召回率。
* **物理常驻内存 (RSS)**：显示当前进程的真实物理内存占用（支持在 32GB 机器上通过层流式运行超大模型，常驻低于 4.0GB）。
* **活跃子系统状态**：清晰查看 CASA、IFR、UBBA、LADDER 四大引擎组件的在线状态。
* **请求历史审计流水**：自动记录近期的每一次请求耗时与吞吐。

### ℹ️ 关于与集成 (About)
展示当前系统引擎版本、连接参数说明，并支持一键切换**深色/浅色主题（Dark/Light Mode）**。

## 3. 兼容 OpenAI 标准 API 接口

本客户端不仅提供网页交互，后台同时完全兼容 OpenAI / Anthropic 标准 API 规范，可无缝对接任何第三方 Agent 或工具链（如 Cursor、Continue、Cline、LangChain 等）：

* **Base URL**: `http://127.0.0.1:8080/v1`
* **API Key**: `not-needed`（任意填写即可）
* **Chat Completion 端点**: `POST http://127.0.0.1:8080/v1/chat/completions`

#### Python 代码调用示例：
```python
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8080/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="qwen2.5:7b",
    messages=[{"role": "user", "content": "你好，请介绍一下你自己！"}],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
```

## 4. 核心技术特性与优势

与传统的 Ollama 原生或 Strata 原版相比，KVMem 客户端在“引擎盖下”拥有以下显著区别：

1. **解决显存暴涨**：传统推理在上下文达到 32K~128K 时，显存直接撑爆；本系统通过 **LADDER 阶梯量化**，将 10M 上下文足迹从 324GB 深度缩减至 42GB。
2. **拒绝上下文失真**：相比把一整块 Key 强行求平均值的粗暴方案（仅 64.5% 召回），本系统采用 **IFR 解耦多子质心**，将检索召回率大幅拉升至 **93.8%**。
3. **超大模型轻薄本可跑**：利用 **CASA 规范存储与 80 层双缓冲流式预取**，32GB 内存电脑也能稳定运行 70B 级大模型，物理内存开销恒定锁死在 4.0GB 以下。

## 5. 常见问题排查 (FAQ)

**Q1：页面顶部指示灯显示 "Ollama 未启动" 或无法生成文本？**  
*答*：本客户端后端默认连接本地推理算子守护进程。请确保已在终端启动服务：
```bash
./bin/ollama serve
```
启动后刷新浏览器页面即可正常对话。

**Q2：如何下载新的模型？**  
*答*：您可以随时使用命令行拉取任意支持的开源模型，例如：
```bash
./bin/ollama pull qwen2.5:7b
./bin/ollama pull qwen2.5:0.5b
```
下载完成后，网页端模型选择下拉框将自动识别并展示新模型。
